# Awesome-Modern-Relationship-Intelligence

## Top Modern Relationship Intelligence Tools Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Relationship Mapping, Network Graph Analytics & CRM Data Enrichment*  
**Last updated: March 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Modern Relationship Intelligence Tools**. These tools automatically capture interactions, map professional networks, enrich CRM records, and surface warm introductions — helping sales, partnerships, and business development teams leverage relationship graphs for revenue growth.

**Examples** include Salesforce Relate, Introhive, Affinity, Nektar.ai, RelSci, BoardEx, DealCloud, People.ai, ZoomInfo Chorus, and Clari (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, custom relationship graphs, and transparent contact intelligence — ideal for revenue operations teams, data engineers, and developers building relationship-aware applications.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

  Relationship intelligence features within Salesforce for mapping connections, tracking interactions, and surfacing warm introductions.

- **[Affinity](https://www.affinity.co/)**

- **[Nektar.ai](https://nektar.ai/)**  
  AI-powered revenue intelligence platform that maps relationships and automates CRM data capture from communications.

- **[RelSci](https://www.relationshipscience.com/)**  
  Relationship mapping platform for accessing professional networks, board connections, and organizational relationships.

- **[BoardEx](https://www.boardex.com/)**  
  Relationship intelligence platform focused on board members, executives, and corporate governance networks.

- **[DealCloud](https://www.dealcloud.com/)**  
  Deal and relationship management platform for financial services with network mapping and interaction tracking.

- **[People.ai](https://people.ai/)**  
  Revenue intelligence platform that captures sales activity, maps buyer relationships, and enriches CRM records.

- **[ZoomInfo Chorus](https://www.zoominfo.com/)**  
  Conversation intelligence platform with relationship mapping, buyer intent signals, and CRM enrichment.

- **[Clari](https://www.clari.com/)**  
  Revenue operations platform with relationship intelligence, forecasting, and pipeline analytics.

## Open-Source GitHub Projects

- **[Apache AGE](https://github.com/apache/age)**  
  PostgreSQL extension for graph database functionality, ideal for building relationship networks and connection queries. Apache 2.0 licensed.

- **[Neo4j Community](https://github.com/neo4j/neo4j)**  
  Leading open-source graph database for modeling professional networks, relationships, and path-finding queries. GPL-3.0 licensed.

- **[Memgraph](https://github.com/memgraph/memgraph)**  
  Open-source in-memory graph database compatible with Cypher, optimized for real-time relationship analytics. BSL licensed.

- **[ArangoDB](https://github.com/arangodb/arangodb)**  
  Multi-model open-source database with graph, document, and key-value capabilities for relationship intelligence. Apache 2.0 licensed.

- **[Dgraph](https://github.com/dgraph-io/dgraph)**  
  Open-source distributed GraphQL-native graph database for large-scale relationship mapping. Apache 2.0 licensed.

- **[JanusGraph](https://github.com/JanusGraph/janusgraph)**  
  Open-source distributed graph database with pluggable storage backends for massive relationship networks. Apache 2.0 licensed.

- **[OrientDB](https://github.com/orientechnologies/orientdb)**  
  Open-source multi-model database with native graph support for social and relationship networks. Apache 2.0 licensed.

- **[NebulaGraph](https://github.com/vesoft-inc/nebula)**  
  Open-source distributed graph database handling billions of vertices and edges for large-scale network analysis. Apache 2.0 licensed.

- **[HugeGraph](https://github.com/apache/incubator-hugegraph)**  
  Apache incubator project for a scalable graph database supporting relationship analytics. Apache 2.0 licensed.

- **[Apache TinkerPop](https://github.com/apache/tinkerpop)**  
  Open-source graph computing framework with Gremlin query language for relationship traversal. Apache 2.0 licensed.

- **[NetworkX](https://github.com/networkx/networkx)**  
  Python library for creating, manipulating, and analyzing complex networks and relationship graphs. BSD-3-Clause licensed.

- **[igraph](https://github.com/igraph/igraph)**  
  Open-source library for network analysis with R, Python, and C interfaces for relationship modeling. GPL-2.0 licensed.

- **[Graphology](https://github.com/graphology/graphology)**  
  JavaScript/TypeScript library for graph data structures and network analytics in browsers and Node.js. MIT licensed.

- **[Gephi](https://github.com/gephi/gephi)**  
  Open-source network visualization and exploration tool for relationship graphs and social networks. GPL-3.0 licensed.

- **[Cytoscape.js](https://github.com/cytoscape/cytoscape.js)**  
  Open-source graph theory library for visualizing and analyzing relationship networks in web apps. MIT licensed.

- **[Sigma.js](https://github.com/jacomyal/sigma.js)**  
  Open-source JavaScript library for graph drawing and network visualization. MIT licensed.

- **[vis.js](https://github.com/visjs/vis-network)**  
  Open-source network visualization library for interactive relationship graphs. Apache 2.0 licensed.

- **[Apache Superset](https://github.com/apache/superset)**  
  Open-source BI platform with graph visualization for relationship analytics dashboards. Apache 2.0 licensed.

- **[Metabase](https://github.com/metabase/metabase)**  
  Open-source analytics tool with network visualization capabilities for relationship data. AGPL-3.0 licensed.

- **[OpenSearch](https://github.com/opensearch-project/OpenSearch)**  
  Open-source search and analytics suite with graph capabilities for relationship exploration. Apache 2.0 licensed.

- **[Elasticsearch](https://github.com/elastic/elasticsearch)**  
  Open-source search engine with graph exploration API for relationship discovery. SSPL licensed.

- **[Suites CRM (SuiteCRM)](https://github.com/salesagility/SuiteCRM)**  
  Open-source CRM with relationship tracking, contact management, and interaction history. AGPL-3.0 licensed.

- **[EspoCRM](https://github.com/espocrm/espocrm)**  
  Open-source CRM with relationship management, email integration, and contact tracking. GPL-3.0 licensed.

- **[Twenty](https://github.com/twentyhq/twenty)**  
  Modern open-source CRM with relationship intelligence features, contact management, and network views. AGPL-3.0 licensed.

- **[Krayin](https://github.com/krayin/laravel-crm)**  
  Open-source CRM with relationship management, lead tracking, and interaction history. MIT licensed.

- **[Odoo CRM](https://github.com/odoo/odoo)**

### Additional Strong Open-Source Options

- **[Open Semantic Search](https://github.com/opensemanticsearch/open-semantic-search)** — Open-source search and relationship discovery platform.
- **[Linkurious](https://github.com/Linkurious)** — Open-source graph visualization and investigation tools.
- **[Graphile](https://github.com/graphile)** — PostgreSQL-based GraphQL and relationship graph tooling.
- **[PostGraphile](https://github.com/graphile/postgraphile)** — Instant GraphQL API for PostgreSQL relationship data.
- **[Hasura](https://github.com/hasura/graphql-engine)** — GraphQL engine with relationship mapping across databases.
- **[Prisma](https://github.com/prisma/prisma)** — Next-generation ORM with relation modeling for relationship data.
- **[Dgraph](https://github.com/dgraph-io/dgraph)** — GraphQL-native graph database for relationships.
- **[Cayley](https://github.com/cayleygraph/cayley)** — Open-source graph database inspired by Google's Knowledge Graph.
- **[RedisGraph](https://github.com/RedisGraph/RedisGraph)** — Graph database module for Redis with Cypher support.
- **[Gun](https://github.com/amark/gun)** — Open-source decentralized graph database for peer-to-peer relationships.
- **Email Parsing** (Mailparser, ImapFlow, Extractous) for capturing interaction data.
- **Calendar Integration** (CalDAV, iCalendar, Nylas SDKs) for meeting relationship tracking.
- **Entity Resolution** (Dedupe, Splink, Zingg) for matching contacts across sources.
- **Graph ML** (PyTorch Geometric, DGL) for link prediction and relationship scoring.

**Frameworks for building custom systems**: Combine **Neo4j** or **NebulaGraph** for the relationship graph, **NetworkX** for analysis, **Cytoscape.js** or **Sigma.js** for visualization, **SuiteCRM** or **Twenty** for CRM data, and **Apache Superset** for dashboards to build a complete self-hosted relationship intelligence stack.
